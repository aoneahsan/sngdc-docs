# About the Author

SNGDC is built and maintained by **Ahsan Mahmood**, a software engineer who builds web and cross-platform mobile applications with React, Capacitor, and Firebase. The same toolchain behind this app — one React codebase shipping to the web and to native Android and iOS, backed by Firestore with client-side security rules and zero paid compute — recurs across a portfolio of products.
